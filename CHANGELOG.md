# Changelog

## 0.9.4-windows.3 — 2026-11-05

- First public Windows source release, based on upstream v0.9.4.
- Preserve the upstream sidebar position and ring design.
- Add per-user logon supervision, guarded normal-icon startup, agent recovery and a fallback desktop launcher.
- Store a private copy of the Node runtime and discover current Windows CLI paths.
- Add ownership checks, cleanup, opt-in live testing and reproducible release packaging.

Validated on one Windows 11 x64 installation. The signed desktop app is not modified. Future internal API compatibility is not guaranteed.
